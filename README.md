# Painel de Acompanhamento de Projetos

Projeto desenvolvido como atividade acadêmica para praticar conceitos de **Git, GitHub e gerenciamento de configuração de software**.

## Objetivo

O objetivo deste projeto é criar uma aplicação web simples para visualizar o andamento de projetos e, ao mesmo tempo, utilizar recursos de controle de versão por meio do GitHub.

## Funcionalidades

- Exibição dos projetos em formato de cartões;
- Identificação do status de cada projeto;
- Visualização do percentual de avanço;
- Indicadores com resumo geral;
- Filtro de projetos por status;
- Ordenação dos projetos pelo percentual de avanço;
- Interface responsiva para computador e celular.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

```text
painel-acompanhamento-projetos/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Clique duas vezes no arquivo `index.html`.
4. O projeto será aberto no navegador.

Não é necessário instalar programas adicionais para executar a página.

## Recursos do GitHub utilizados

Durante a atividade, podem ser explorados os seguintes recursos:

- **Repositório:** armazenamento dos arquivos do projeto;
- **Commit:** registro das alterações realizadas;
- **Branch:** criação de uma ramificação para testar mudanças;
- **Histórico:** acompanhamento das versões e alterações;
- **README:** documentação e apresentação do projeto.
